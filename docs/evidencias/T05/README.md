### 7. Acuerdos de trabajo del equipo

#### 7.1 Entregable

| Aspecto | Acuerdo |
|---|---|
| Ritmo de reuniones | Una reunión virtual por semana, preferiblemente los miércoles. Si no es posible, una sesión de menos de media hora los sábados. Las reuniones de sprint se harán en horarios en los que puedan participar todos los integrantes. |
| Canal de comunicación | WhatsApp. |
| Planificación y control | Tablero de planificación y repositorio en GitHub; Netlify para publicar la demostración. |
| Herramientas de software | React 19, TypeScript, Vite y CSS Modules (frontend); Node.js con Express 5 (API); SQL Server con las bases VERTEX_DEMO y VERTEX_REAL. |
| Equipo de cómputo | Equipo del responsable técnico: HP, procesador Intel Core i5, gráficos Intel y 8 GB de RAM. Los demás integrantes trabajan con Windows o Linux. Las tareas se asignan según el equipo y el sistema operativo de cada integrante, para que ninguno se bloquee por falta de máquina. |
| Documentación | Dossier de diseño (DERS), caso de negocio, documento de flujo de datos y este taller. |

Compromisos del equipo:

- Mantener la lógica de negocio en procedimientos almacenados, según el lineamiento de TI.
- No publicar contraseñas, secretos ni valores de configuración en el repositorio.
- Mantener separados los ambientes de demostración y real.
- Revisar cada cambio en local y documentarlo antes de publicarlo.
- Cumplir las tareas de cada sprint en las fechas del plan.

#### 7.2 Evolución futura

| Aspecto | Acuerdo |
|---|---|
| Herramientas de hardware (Etapa A) | Microcontrolador ESP32, medidor PZEM-004T, sensores de vibración y temperatura, baterías 18650, módulos TP4056 y LM2596, microSD y caja IP65. |
| Infraestructura de TI | Servidor en planta con respaldo fuera de planta, red segmentada, SQL Server corporativo y autenticación con Directorio Activo. |

Compromisos del equipo:

- Validar con Mantenimiento las reglas de cálculo y los umbrales antes de trabajar con datos reales.
- Cumplir las actividades de la Etapa A según el cronograma que se acuerde con la empresa.
